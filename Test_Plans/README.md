# Performance Test Plan – Sample

## Objective
To evaluate the performance, scalability, and stability of a web and API-based application under expected and peak user loads.

## Scope
- Web application performance testing
- API performance testing
- Load, Stress, and Endurance testing

## Test Types
- Load Testing
- Stress Testing
- Endurance Testing

## Tools Used
- LoadRunner
- JMeter
- Postman

## Entry Criteria
- Application deployed in test environment
- Test data available

## Exit Criteria
- All performance metrics captured
- Bottlenecks identified and reported
